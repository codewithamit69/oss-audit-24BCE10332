## 📌 Project Description
This project is an audit of the open-source software Git. It includes theoretical analysis and practical implementation using Linux and shell scripting.

---

## 🧾 Scripts Included

### Script 1 — System Identity Report
Displays system information such as kernel, user, uptime, and OS details.

### Script 2 — Package Inspector
Checks if Git is installed and shows version and description.

### Script 3 — Disk and Permission Auditor
Analyzes directories for permissions, ownership, and disk usage.

### Script 4 — Log File Analyzer
Counts occurrences of a keyword in a log file.

### Script 5 — Manifest Generator
Generates a personalized open-source manifesto.
